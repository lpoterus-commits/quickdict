# QuickDict

**韓国語学習者のための macOS 辞書引きツール。** 画面上のどんな韓国語でも — スキャンした教科書、PDF、
動画の字幕、ウェブページ、誰かが送ってきたスクリーンショット — その場で辞書を引けます。
認識はすべてこの Mac の中で完結します。ネット接続なし、送信なし、履歴なし。

言語: [English](README.md) · [中文](README.zh-CN.md) · [Русский](README.ru.md) ·
[Tiếng Việt](README.vi.md) · **日本語** · [한국어](README.ko.md)

## ほかと違うところ

画面から文字を読むツールはいくらでもあります。これは**改行で切れた韓国語の単語をつなぎ直します**。

折り返しのある段落を認識すると、行末の単語が真っ二つになります。`이성적인`（理性的な）が
`이` + `성적인` になり、素直につなぐと `이 성적인` — まったく別の意味になってしまう。
それらを隔てていたスペースは改行に吸収されていて、**ピクセル上には存在しません。**

3 つの方法が行き止まりでした：

| 試したこと | 結果 |
|---|---|
| システムの韓国語スペルチェック | ✗ 正しいハングル音節の並びなら何でも通してしまう |
| NaturalLanguage の韓国語トークナイザ | ✗ スペースで区切るだけで、形態素解析はしない |
| 幾何情報だけ（行が右端まで届いているか） | △ 折り返しと段落末は区別できるが、単語の途中で切れたのかスペースで切れたのかは区別できない |

実際に動く解は 3 つの手がかりの組み合わせです：

1. **システムの韓国語辞書**（`DCSCopyTextDefinition`）— 半分どうしをつないで、辞書に載っている最長の
   前置部分が**継ぎ目をまたぐか**を見ます。`이` + `성적인` → `이성적` は辞書にあり、長さ 3 は継ぎ目の
   手前の 1 文字より長い → 単語が切れていた、と判定。
2. **行の幾何情報** — Vision が返す行ごとの矩形から、その行が押し出されて切れたのか自然に終わったのかを見ます。
3. **韓国語の助詞・語尾の表** — 行頭に浮いている `은` / `는` / `로서` / `하며` / `진다고` は、
   前の行の単語の後半でしかありえません。

ラテン文字は別の道を通ります。英語のスペルチェックは本物の辞書なので、`jum` + `ps` = `jumps` は
経験則ではなく辞書引きで決まります。

**リポジトリに 28 個の結合テスト**があり、すべて通っています。

語尾の表は**設定ファイルから足せます**。抜けに気づいたら、コードを触らず、新版を待たずに自分で直せます：

```jsonc
"koreanExtraParticles":  ["로부터", "에서부터"],
"koreanExtraStandalone": ["뭐"]
```

足した分は組み込みの表を*置き換える*のではなく*併合*されるので、更新もそのまま効き続けます。

### 判断できないときは、そう言います

`이성적인`（理性的な）と `이 성적인`（この〜的な）は**どちらも正しい韓国語**です。改行がちょうどその
間に落ちたとき、ローカルのどんな手がかりでも区別できません。文脈だけが決められることで、それには
言語モデルが要ります。そこで QuickDict は既定でつなぎ（こちらのほうがずっと多いため）、
**判断せざるをえなかった箇所を知らせます**：

```
87 文字をコピーしました
⚠️ ここはつなげましたが、分けて書いても意味が通ります：
이성적인
```

ふつう 1 段落あたり 0〜1 箇所なので、ノイズではなく手がかりとして機能します。

## 使い方

| ショートカット | 文字の取得元 | 動作 |
|---|---|---|
| `⌃⌥9` | スクリーンショット + 認識 | 辞書を引く、言語は自動判定 |
| `⌃⌥0` | スクリーンショット + 認識 | **行をつないでクリップボードへ**、辞書は引かない（オフラインで動作） |
| `⌃⌥8` | スクリーンショット | **QR コード・バーコードを読む**、URL ならブラウザで開く |
| `⌘⌥D` | 選択中の文字 | 辞書を引く、言語は自動判定 |
| `⌘⌥N` | 選択中の文字 | Naver へ直行（あなたの言語のもの） |
| `⌘⌥K` | 選択中の文字 | 국어사전（韓韓辞典）へ直行 |
| `⌘⌥P` | 選択中の文字 | Papago へ直行 |
| `⌘⌥G` | 選択中の文字 | Google 翻訳へ直行 |

**スクリーンショット**は選択できない文字向け — 画像、スキャンした PDF、動画の字幕。
**選択**は選べる文字向けで、認識ミスがなく速い。

辞書ごとのキーは**その言語に実際にある辞書から生成**されるので、効かないショートカットはできません。

| そのほか | |
|---|---|
| `⌘1`…`⌘9` | 結果ウインドウで辞書を切り替え |
| `⌘L` | 誤認識した語を直して Enter で再検索 |
| `esc` / `⌘W` | ウインドウを閉じる |
| コンパスのボタン | 今の検索語をデフォルトのブラウザへ |
| ピンのボタン | ウインドウを最前面に固定 |

**ショートカットを忘れたら `⌘?`**。内蔵の説明は現在の設定から生成されるので、内容が古くなりようがありません。

## インストール

**macOS 13 以降**が必要です。ユニバーサルバイナリ — Apple Silicon と Intel の両方で動きます。

```bash
git clone https://github.com/lpoterus-commits/quickdict.git && cd quickdict
./build.sh install
```

必要なのは Command Line Tools だけで、Xcode 本体は不要です。ビルドは 1 分ほど。

> **QuickDict 3.app** という名前で入ります。古いバージョン 2 と並べて使えるようにするためです。
> ただ `QuickDict` にしたい場合は `build.sh` の `APP_NAME` を書き換えてください。

### 開けないとき

ダウンロードした `.zip` の場合、Apple の公証を受けていないアプリは macOS が止めます。
「**「QuickDict 3」は壊れているため開けません**」と出ますが、**壊れていません** —
macOS はインターネット由来のものすべてに印を付けます。公証は年 99 ドルかかり、このプロジェクトはそれを払っていません。

回避方法は 3 つ：

**1. 自分でビルドする**（上のコマンド）。ローカルでコンパイルしたものには印が付きません。いちばん綺麗な方法です。

**2. ダウンロードしてコマンドを 1 回実行する。** ターミナルに貼り付けて実行すれば、あとは普通に開けます：

```bash
xattr -dr com.apple.quarantine "/Applications/QuickDict 3.app"
```

**1 回だけで済みます**。印が戻ることはありません。外してもアプリは変わらず、弱くもなりません：
コード署名は有効なままで、自分でビルドした場合とまったく同じように動きます。

**3. 誰かに直接渡してもらう。** この印はブラウザ・メール・AirDrop が付けます。**USB メモリや外付けドライブから
コピーしたものには印が付かず**、ダブルクリックで開きます — ターミナルは要りません。

### 権限

どちらも**システム設定 → プライバシーとセキュリティ**にあります。**許可したらアプリを再起動してください** —
macOS は新しく起動したプロセスにしか権限を適用しません。設定アシスタントが両方を案内し、状態を随時表示します。

| 権限 | 用途 | 許可しないと |
|---|---|---|
| 画面収録 | 取り込む範囲のドラッグ | スクリーンショット系の操作がすべて動きません |
| アクセシビリティ | 他のアプリで選択した文字の読み取り | 選択を使う操作がすべて動きません |

## 辞書の言語

初回起動時にシステムの言語から選ばれます。メニューバーの**「調べる言語」**でいつでも切り替えられます。

| | Naver 辞書 | 翻訳 |
|---|---|---|
| English | `en.dict.naver.com` | `en` |
| 中文 | `zh.dict.naver.com` | `zh-CN` |
| 日本語 | `ja.dict.naver.com` | `ja` |
| 한국어 | `ko.dict.naver.com` | `ko` |
| Русский | `dict.naver.com/rukodict` | `ru` |
| Tiếng Việt | `dict.naver.com/vikodict` | `vi` |
| Italiano | `dict.naver.com/itkodict` | `it` |

Naver の辞書は**双方向**です。`사랑` → `愛` も `愛` → `사랑` も同じ辞書で引けます。
韓国語を読むときは意味を、韓国語を書くときは言い方を、どちらも同じところで調べられます。

### 自分で辞書を足す

プリセットは「韓国語をあなたの言語で引く」ためのものです。それ以外 — 専門辞書、別の言語ペア、
気に入っているサイト — を足したいときは、メニューバーの**「設定ファイルを編集」**から
`dictionaries` に 1 項目書き足します：

```jsonc
{
  "id": "yihan",                              // 一意な名前なら何でも
  "name": "伊中辞典",                          // ボタンに出る名前
  "languages": ["it"],                        // イタリア語を認識したら自動で開く
  "url": "https://www.yihan.it/{q}"           // {q} が検索語の位置
}
```

そのあとメニューバーの**「設定を読み込み直す」**を押します。省略可能な項目：

| 項目 | 意味 |
|---|---|
| `languages` | どの言語を認識したとき自動で開くか。`"*"` はフォールバック、`[]` は手動のみ |
| `suffix` | URL エンコード**前**に検索語の後ろへ足される。検索エンジンや AI への質問文に便利 |
| `external` | `true` にすると内蔵ウインドウではなくデフォルトのブラウザで開く（ログインが要るサイト用） |

**自分で足した項目はどの操作でも残ります** — 母語を変えても、調べる言語を増やしても、足したものには触れません。

何が開くかは 2 つの軸で決まります：

- **調べる言語** — 1 つだけ。語義がこの言語で出ます。メニューバー →「調べる言語」
- **他に調べる言語** — どの外国語に出くわすか。メニューバー →「他に調べる言語」で好きなだけチェック

韓国語は Naver の二言語辞書へ。チェックしたそれ以外の言語にはそれぞれ Glosbe
（`glosbe.com/<元>/<先>/<語>`）が付きます。ほぼどんな組み合わせもあります。
イタリア語を選べばイタリア語辞書が、韓国語を選べば Naver が開きます。手で切り替える必要はありません。

**自分で足した項目がある言語を名乗ると、その言語の既定の項目を置き換えます。**

### ウェブサイトの代わりに辞書アプリを使う

辞書アプリが入っていれば、ウェブページではなくそれを直接開けます。メニューバー →
**ローカルの辞書アプリ**に、この Mac に**実際に入っているもの**だけが並びます。入っていないものは出ません。

こうできるのは、辞書アプリが独自の URL スキームを登録していて、`external` を付けた項目は内蔵ウインドウで
読み込まずシステムに渡されるからです：

```jsonc
{ "id": "local-eudic", "name": "Eudic", "languages": ["en"],
  "url": "eudic://dict/{q}", "external": true }
```

チェックすると**手動専用**として追加されます — 辞書アプリはたいてい多言語対応なので、どの言語を任せるかは
あなたが決めることです。`languages` を書けば自動になり、その言語を完全に引き受けます。

設定ファイル：`~/Library/Application Support/com.quickdict.app/config.json`

プリセットへの言語追加とソースの構成は [英語版 README](README.md) をご覧ください。
