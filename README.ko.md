# QuickDict

**한국어를 배우는 사람을 위한 macOS 사전 도구.** 화면에 있는 어떤 한국어든 — 스캔한 교재, PDF,
영상 자막, 웹페이지, 누가 보내준 스크린샷 — 그 자리에서 사전을 찾습니다.
인식은 전부 이 Mac 안에서 끝납니다. 인터넷 연결 없음, 전송 없음, 기록 없음.

언어: [English](README.md) · [中文](README.zh-CN.md) · [Русский](README.ru.md) ·
[Tiếng Việt](README.vi.md) · [日本語](README.ja.md) · **한국어**

---

## 무엇이 다른가

화면에서 글자를 읽는 도구는 많습니다. 이것은 **줄바꿈으로 끊긴 한국어 낱말을 다시 이어 붙입니다**.

줄이 넘어가는 문단을 인식하면 줄 끝의 낱말이 반으로 잘립니다. `이성적인`이 `이` + `성적인`이 되고,
그대로 이으면 `이 성적인` — 뜻이 완전히 달라집니다. 둘을 갈라놓던 띄어쓰기는 줄바꿈이 삼켜버려서
**픽셀 위에는 존재하지 않습니다.**

세 가지 방법이 막다른 길이었습니다:

| 시도 | 결과 |
|---|---|
| 시스템 한국어 맞춤법 검사 | ✗ 올바른 한글 음절이 이어져 있기만 하면 무엇이든 통과시킴 |
| NaturalLanguage 의 한국어 토크나이저 | ✗ 띄어쓰기로만 나눔, 형태소 분석은 하지 않음 |
| 기하 정보만 사용 (줄이 오른쪽 끝까지 닿았는가) | △ 줄바꿈과 문단 끝은 구별하지만, 낱말 중간에서 끊긴 것과 띄어쓰기에서 끊긴 것은 구별 못 함 |

실제로 되는 방법은 세 신호를 합치는 것입니다:

1. **시스템 한국어 사전**(`DCSCopyTextDefinition`) — 두 조각을 이어 붙인 뒤, 사전에 있는 가장 긴
   앞부분이 **이음매를 넘어가는지** 봅니다. `이` + `성적인` → `이성적`이 사전에 있고 길이 3 은
   이음매 앞의 1 자보다 기니까 → 낱말이 잘린 것.
2. **줄의 기하 정보** — Vision 이 주는 줄별 사각형으로, 그 줄이 밀려서 끊긴 것인지 스스로 끝난 것인지 판단.
3. **한국어 조사·어미 표** — 줄 첫머리에 떠 있는 `은` / `는` / `로서` / `하며` / `진다고` 는
   앞줄 낱말의 뒷부분일 수밖에 없습니다.

로마자는 길이 다릅니다. 영어 맞춤법 검사는 진짜 사전이라서 `jum` + `ps` = `jumps` 는
어림짐작이 아니라 사전 조회로 결정됩니다.

**저장소에 통합 테스트 28 개**가 있고 모두 통과합니다.

어미 표는 **설정 파일에서 보탤 수 있습니다.** 빠진 것을 발견하면 코드를 건드리지 않고, 새 버전을
기다리지 않고 직접 고칠 수 있습니다:

```jsonc
"koreanExtraParticles":  ["로부터", "에서부터"],
"koreanExtraStandalone": ["뭐"]
```

보탠 것은 내장 표를 *바꾸는* 게 아니라 *합쳐집니다*. 그래서 업데이트도 계속 적용됩니다.

### 알 수 없을 때는 그렇다고 말합니다

`이성적인`과 `이 성적인`은 **둘 다 맞는 한국어**입니다. 줄바꿈이 딱 그 사이에 떨어지면 어떤 국소
신호로도 구별할 수 없습니다. 문맥만이 정할 수 있고, 그러려면 언어 모델이 필요합니다. 그래서
QuickDict 는 기본적으로 붙이되(이쪽이 훨씬 흔하므로), **판단해야 했던 곳을 알려 줍니다**:

```
87자를 복사했습니다
⚠️ 여기는 붙여 썼지만, 띄어 써도 말이 됩니다:
이성적인
```

보통 한 문단에 0~1 곳이라, 잡음이 아니라 힌트로 쓸 만합니다.

## 쓰는 법

| 단축키 | 글자를 가져올 곳 | 하는 일 |
|---|---|---|
| `⌃⌥9` | 화면 캡처 + 인식 | 사전 찾기, 언어는 자동 판별 |
| `⌃⌥0` | 화면 캡처 + 인식 | **줄을 이어 붙여 클립보드로**, 사전은 안 찾음 (인터넷 없이도 동작) |
| `⌃⌥8` | 화면 캡처 | **QR 코드·바코드 읽기**, 주소면 브라우저로 열기 |
| `⌘⌥D` | 선택한 글자 | 사전 찾기, 언어는 자동 판별 |
| `⌘⌥N` | 선택한 글자 | Naver 로 바로 (당신 언어의 것) |
| `⌘⌥K` | 선택한 글자 | 국어사전으로 바로 |
| `⌘⌥P` | 선택한 글자 | Papago 로 바로 |
| `⌘⌥G` | 선택한 글자 | Google 번역으로 바로 |

**캡처 방식**은 선택할 수 없는 글자용입니다 — 이미지, 스캔한 PDF, 영상 자막.
**선택 방식**은 고를 수 있는 글자용이라 인식 오류가 없고 더 빠릅니다.

사전별 단축키는 **그 언어에 실제로 있는 사전에서 만들어지므로**, 먹통인 단축키가 생기지 않습니다.

| 그 밖에 | |
|---|---|
| `⌘1`…`⌘9` | 결과 창에서 사전 바꾸기 |
| `⌘L` | 잘못 인식된 낱말을 고치고 Enter 로 다시 찾기 |
| `esc` / `⌘W` | 창 닫기 |
| 나침반 버튼 | 지금 검색어를 기본 브라우저로 |
| 압정 버튼 | 창을 맨 앞에 고정 |

**단축키가 기억나지 않으면 `⌘?`**. 내장 설명은 지금 설정에서 만들어지므로 내용이 낡을 수가 없습니다.

## 오프라인 사전 내장

국립국어원 한국어기초사전(56,555 항목, CC BY-SA 2.0 KR)을 함께 넣었습니다.
**예비용**입니다. 온라인에서는 그대로 네이버를 쓰고, **연결이 끊겼을 때만** 자동으로 넘어갑니다.

사전에는 기본형만 있어서 OCR로 잡히는 활용형(갔어요·몰랐어)은 그대로는 찾을 수 없습니다.
그래서 음절 구조로 기본형을 복원한 뒤에 찾습니다(ㅂ/ㄷ/ㅅ/ㄹ/르/ㅎ 불규칙과 모음 축약 포함, 회귀 테스트 30건).

> 라이선스와 변경 내용은 [KRDICT-NOTICE.md](Resources/KRDICT-NOTICE.md) 참고.

## 설치

**macOS 13 이상**이 필요합니다. 유니버설 바이너리 — Apple Silicon 과 Intel 모두 동작합니다.

```bash
git clone https://github.com/lpoterus-commits/quickdict.git && cd quickdict
./build.sh install
```

Command Line Tools 만 있으면 되고 Xcode 전체는 필요 없습니다. 빌드는 1 분 정도 걸립니다.

> **QuickDict 3.app** 이라는 이름으로 설치됩니다. 예전 버전 2 와 나란히 쓸 수 있게 하기 위해서입니다.
> 그냥 `QuickDict` 로 하고 싶으면 `build.sh` 의 `APP_NAME` 을 고치세요.

### 열리지 않을 때

내려받은 `.zip` 은, Apple 공증을 받지 않은 앱이면 macOS 가 막습니다.
「**"QuickDict 3"이(가) 손상되어 열 수 없습니다**」라고 나오지만 **손상된 것이 아닙니다** —
macOS 는 인터넷에서 온 것에 전부 표시를 붙입니다. 공증은 1 년에 99 달러가 들고, 이 프로젝트는 그 돈을 쓰지 않습니다.

방법은 세 가지:

**1. 직접 빌드하기**(위 명령). 직접 컴파일한 파일에는 표시가 붙지 않습니다. 가장 깔끔합니다.

**2. 내려받은 뒤 명령 한 줄 실행.** 터미널에 한 번 붙여넣으면, 그다음부터는 그냥 열면 됩니다:

```bash
xattr -dr com.apple.quarantine "/Applications/QuickDict 3.app"
```

**한 번이면 끝**이고 표시가 다시 붙지 않습니다. 없앤다고 앱이 바뀌거나 약해지지 않습니다:
코드 서명은 그대로 유효하고, 직접 빌드한 것과 똑같이 동작합니다.

**3. 누군가에게 직접 받기.** 이 표시는 브라우저, 메일, AirDrop 이 붙입니다. **USB 메모리나 외장 디스크에서
복사한 파일에는 표시가 없어서** 더블클릭으로 열립니다 — 터미널이 필요 없습니다.

### 권한

둘 다 **시스템 설정 → 개인정보 보호 및 보안**에 있습니다. **허용한 뒤에는 앱을 다시 실행해야 합니다** —
macOS 는 새로 시작한 프로세스에만 권한을 적용합니다. 설정 도우미가 둘 다 안내하고 상태를 실시간으로 보여줍니다.

| 권한 | 용도 | 허용하지 않으면 |
|---|---|---|
| 화면 기록 | 가져올 영역 끌어서 고르기 | 캡처 관련 기능이 전부 안 됩니다 |
| 손쉬운 사용 | 다른 앱에서 선택한 글자 읽기 | 선택 관련 기능이 전부 안 됩니다 |

## 사전 언어

처음 실행할 때 시스템 언어를 보고 고릅니다. 메뉴 막대의 **「찾을 언어」**에서 언제든 바꿀 수 있습니다.

| | Naver 사전 | 번역기 |
|---|---|---|
| English | `en.dict.naver.com` | `en` |
| 中文 | `zh.dict.naver.com` | `zh-CN` |
| 日本語 | `ja.dict.naver.com` | `ja` |
| 한국어 | `ko.dict.naver.com` | `ko` |
| Русский | `dict.naver.com/rukodict` | `ru` |
| Tiếng Việt | `dict.naver.com/vikodict` | `vi` |
| Italiano | `dict.naver.com/itkodict` | `it` |

Naver 사전은 **양방향**입니다. `사랑` → `love` 도, `love` → `사랑` 도 같은 사전에서 찾습니다.
한국어를 읽을 때는 뜻을, 한국어를 쓸 때는 표현을 — 같은 곳에서 해결됩니다.

### 사전을 직접 추가하기

프리셋은 「한국어를 당신의 언어로 찾기」를 맡습니다. 그 밖의 것 — 전문 사전, 다른 언어 쌍,
자주 쓰는 사이트 — 을 넣고 싶으면 메뉴 막대의 **「설정 파일 편집」**을 열고 `dictionaries` 에
한 항목을 더하세요:

```jsonc
{
  "id": "yihan",                              // 겹치지 않는 이름이면 아무거나
  "name": "이탈리아어-중국어",                    // 버튼에 보이는 이름
  "languages": ["it"],                        // 이탈리아어를 인식하면 자동으로 열림
  "url": "https://www.yihan.it/{q}"           // {q} 가 검색어 자리
}
```

그다음 메뉴 막대에서 **「설정 다시 읽기」**를 누릅니다. 선택 항목:

| 항목 | 뜻 |
|---|---|
| `languages` | 어떤 언어를 인식했을 때 자동으로 열지. `"*"` 는 기본값, `[]` 는 수동으로만 |
| `suffix` | URL 인코딩 **전에** 검색어 뒤에 붙습니다 — 검색 엔진이나 AI 질문에 유용 |
| `external` | `true` 면 내장 창 대신 기본 브라우저로 엽니다 (로그인이 필요한 사이트용) |

**직접 넣은 항목은 어떤 조작에도 남습니다** — 모국어를 바꾸든, 찾을 언어를 더하든, 넣은 것은 건드리지 않습니다.

무엇이 열릴지는 두 축이 정합니다:

- **찾을 언어** — 하나. 뜻이 이 언어로 나옵니다. 메뉴 막대 →「찾을 언어」
- **함께 찾을 언어** — 어떤 외국어를 마주치는지. 메뉴 막대 →「함께 찾을 언어」에서 원하는 만큼 체크

한국어는 Naver 이중언어 사전으로, 체크한 다른 언어는 각각 Glosbe
(`glosbe.com/<출발>/<도착>/<낱말>`) 항목이 붙습니다. 사실상 모든 언어 쌍이 있습니다.
이탈리아어 낱말을 고르면 이탈리아어 사전이, 한국어를 고르면 Naver 가 열립니다. 직접 바꿀 필요가 없습니다.

**직접 넣은 항목이 어떤 언어를 맡으면, 그 언어의 기본 항목을 대체합니다.**

### 웹사이트 대신 사전 앱 쓰기

사전 앱이 깔려 있으면 웹페이지 대신 그것을 바로 열 수 있습니다. 메뉴 막대 →
**설치된 사전 앱**에 이 Mac 에 **실제로 깔린 것만** 나옵니다. 안 깔린 것은 보이지 않습니다.

이게 되는 이유는 그런 앱들이 자기 URL 스킴을 등록해 두었고, `external` 로 표시된 항목은 내장 창에서
불러오지 않고 시스템에 넘기기 때문입니다:

```jsonc
{ "id": "local-eudic", "name": "Eudic", "languages": ["en"],
  "url": "eudic://dict/{q}", "external": true }
```

체크하면 **수동 전용**으로 들어갑니다 — 사전 앱은 보통 여러 언어를 다루니, 어떤 언어를 맡길지는
당신이 정할 일입니다. `languages` 를 적어 주면 자동이 되고, 그 언어를 완전히 가져갑니다.

설정 파일: `~/Library/Application Support/com.quickdict.app/config.json`

프리셋에 언어를 추가하는 방법과 소스 구조는 [영어 README](README.md) 를 보세요.
