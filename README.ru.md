# QuickDict

**Программа для macOS, помогающая изучать корейский.** Захватите любой корейский текст на экране —
отсканированный учебник, PDF, субтитры, веб-страницу, чей-то скриншот — и сразу получите словарную
статью. Всё распознавание идёт на вашем Mac — без телеметрии и без истории. Выходит ли поиск в сеть,
зависит от выбранного словаря: встроенная офлайн-база и ваши заметки — нет, веб-словари — разумеется, да.

Языки: [English](README.md) · [中文](README.zh-CN.md) · **Русский** · [Tiếng Việt](README.vi.md) ·
[日本語](README.ja.md) · [한국어](README.ko.md)

## Чем отличается

Прочитать текст с экрана умеют многие программы. Эта **склеивает корейские слова, разорванные
переносом строки**.

Когда вы распознаёте абзац с переносами, слово на конце строки разрывается пополам. `이성적인`
(*рациональный*) превращается в `이` + `성적인`, и наивная склейка даёт `이 성적인` — а это уже совсем
другой смысл. Пробел, который их разделял, поглощён переносом строки; **в пикселях его нет.**

Три подхода не сработали:

| Попытка | Результат |
|---|---|
| Системная проверка орфографии корейского | ✗ Принимает любую последовательность корректных слогов хангыля |
| Токенизатор корейского в NaturalLanguage | ✗ Делит только по пробелам, без морфологического разбора |
| Только геометрия (строка дотянута до края?) | △ Отличает перенос от конца абзаца, но не разрыв внутри слова от разрыва на пробеле |

Работающее решение соединяет три сигнала:

1. **Системный корейский словарь** (`DCSCopyTextDefinition`) — склеить половинки и проверить, не
   **пересекает ли шов** самый длинный словарный префикс. `이` + `성적인` → `이성적` есть в словаре,
   длина 3 больше одного символа до шва → слово было разорвано.
2. **Геометрия строк** — рамки строк из Vision показывают, была строка обрезана или закончилась сама.
3. **Таблица корейских частиц и окончаний** — висящее `은` / `는` / `로서` / `하며` / `진다고` в начале
   строки может быть только хвостом предыдущего слова.

Для латиницы путь другой: английская проверка орфографии — настоящий словарь, поэтому
`jum` + `ps` = `jumps` решается поиском по словарю, а не эвристикой.

**28 интеграционных тестов в репозитории**, все проходят.

Таблицу окончаний **можно дополнять прямо из файла настроек** — если заметили пропуск, поправьте сами,
без правки кода и без ожидания новой версии:

```jsonc
"koreanExtraParticles":  ["로부터", "에서부터"],
"koreanExtraStandalone": ["뭐"]
```

Ваши дополнения *объединяются* со встроенной таблицей, а не заменяют её, поэтому обновления продолжают действовать.

### Когда однозначно решить нельзя — программа об этом говорит

`이성적인` (*рациональный*) и `이 성적인` (*этот ~альный*) — **оба варианта корректны по-корейски**.
Если перенос попал ровно между ними, никакой локальный сигнал их не различит: нужен контекст, а значит
языковая модель. Поэтому QuickDict по умолчанию склеивает (так встречается гораздо чаще), но
**сообщает о местах, где пришлось решать**:

```
Скопировано символов: 87
⚠️ Здесь склеено, но раздельное написание тоже допустимо:
이성적인
```

Обычно 0–1 отметка на абзац — это подсказка, а не шум.

## Как пользоваться

| Сочетание | Откуда текст | Действие |
|---|---|---|
| `⌃⌥9` | Снимок экрана + распознавание | Найти, язык определяется сам |
| `⌃⌥0` | Снимок экрана + распознавание | **Склеить строки и скопировать**, без словаря (работает без интернета) |
| `⌃⌥8` | Снимок экрана | **Прочитать QR-код или штрихкод**, ссылку открыть в браузере |
| `⌘⌥D` | Выделенный текст | Найти, язык определяется сам |
| `⌘⌥N` | Выделенный текст | Сразу в Naver (для вашего языка) |
| `⌘⌥K` | Выделенный текст | Сразу в 국어사전 (корейско-корейский) |
| `⌘⌥P` | Выделенный текст | Сразу в Papago |
| `⌘⌥G` | Выделенный текст | Сразу в Google Translate |

**Режим снимка** — для текста, который нельзя выделить: изображения, отсканированные PDF, субтитры.
**Режим выделения** — для выделяемого текста: без ошибок распознавания и быстрее.

Клавиши для конкретных словарей создаются **из тех словарей, которые есть у вашего языка**, так что
нерабочих сочетаний не бывает.

| Ещё | |
|---|---|
| `⌘1`…`⌘9` | Сменить словарь в окне результата |
| `⌘L` | Исправить распознанное слово, Enter — искать снова |
| `esc` / `⌘W` | Закрыть окно |
| Кнопка компаса | Отправить запрос в браузер по умолчанию |
| Кнопка кнопки-скрепки | Держать окно поверх остальных |

**Не помните сочетания — нажмите `⌘?`**: встроенное руководство собирается из вашей текущей
конфигурации, поэтому оно не может устареть.

## Встроенный офлайн-словарь

В приложение вложен корейско-китайский словарь Национального института корейского языка
(56 555 статей, CC BY-SA 2.0 KR). Это **запасной вариант**: онлайн по-прежнему открывается Naver,
а локальная база подхватывает **только при пропаже сети** — переключать ничего не нужно.

В базе лежат словарные формы, а распознаётся всегда изменённая (갔어요, 몰랐어), поэтому перед
поиском форма восстанавливается по строению корейского слога (неправильные ㅂ/ㄷ/ㅅ/ㄹ/르/ㅎ
и стяжение гласных, 30 регрессионных тестов).

> Лицензия и перечень изменений — [KRDICT-NOTICE.md](Resources/KRDICT-NOTICE.md).

## Установка

Нужна **macOS 13+**. Универсальный бинарник — Apple Silicon и Intel.

```bash
git clone https://github.com/lpoterus-commits/quickdict.git && cd quickdict
./build.sh install
```

Достаточно Command Line Tools, полный Xcode не нужен. Сборка занимает около минуты.

> Программа ставится как **QuickDict 3.app**, чтобы могла работать рядом со старой версией 2.
> Измените `APP_NAME` в `build.sh`, если хотите просто `QuickDict`.

### Если программа не открывается

Скачанные `.zip` macOS блокирует, если приложение не нотаризовано Apple. Вы увидите
*«Объект „QuickDict 3“ повреждён и не может быть открыт»*. **Программа не повреждена** — macOS помечает
всё, что пришло из интернета. Нотаризация стоит $99 в год, и этот проект их не тратит.

Три способа обойти:

**1. Соберите сами** (команда выше). То, что вы скомпилировали локально, никогда не помечается. Самый чистый путь.

**2. Скачайте и выполните одну команду.** Вставьте это в Терминал один раз, дальше открывайте как обычно:

```bash
xattr -dr com.apple.quarantine "/Applications/QuickDict 3.app"
```

Достаточно одного раза — метка больше не появится. Её снятие ничего не меняет и не ослабляет:
подпись остаётся действительной, всё работает ровно так же, как если бы вы собрали программу сами.

**3. Пусть вам передадут файл напрямую.** Метку ставят браузеры, почта и AirDrop. Копия с флешки или
внешнего диска не имеет метки вовсе и открывается двойным щелчком — Терминал не нужен.

### Разрешения

Оба — в **Системных настройках → Конфиденциальность и безопасность**. **После выдачи перезапустите
программу**: macOS применяет разрешения только к заново запущенному процессу. Помощник настройки
проведёт вас по обоим и показывает состояние в реальном времени.

| Разрешение | Зачем | Без него |
|---|---|---|
| Запись экрана | Выделение области для снимка | Не работают действия со снимком |
| Универсальный доступ | Чтение выделенного текста в других программах | Не работают действия с выделением |

## Язык словарей

Выбирается по языку системы при первом запуске; сменить можно в любой момент через строку меню
(**Искать перевод на**).

| | Словарь Naver | Переводчики |
|---|---|---|
| English | `en.dict.naver.com` | `en` |
| 中文 | `zh.dict.naver.com` | `zh-CN` |
| 日本語 | `ja.dict.naver.com` | `ja` |
| 한국어 | `ko.dict.naver.com` | `ko` |
| Русский | `dict.naver.com/rukodict` | `ru` |
| Tiếng Việt | `dict.naver.com/vikodict` | `vi` |
| Italiano | `dict.naver.com/itkodict` | `it` |

Словари Naver **двусторонние**: `사랑` → `любовь` и `любовь` → `사랑` ищутся в одном и том же словаре.
Читаете по-корейски — смотрите значение; пишете по-корейски — ищете, как сказать.

### Как добавить свой словарь

Пресеты решают задачу «искать корейское слово на вашем языке». Чтобы добавить что-то ещё —
специализированный словарь, другую языковую пару, любимый сайт — откройте **Изменить файл настроек**
в строке меню и допишите одну запись в `dictionaries`:

```jsonc
{
  "id": "yihan",                              // любое уникальное имя
  "name": "Итальянско-китайский",             // подпись на кнопке
  "languages": ["it"],                        // открывается сам для итальянского текста
  "url": "https://www.yihan.it/{q}"           // {q} — место запроса
}
```

Затем **Перезагрузить настройки** в строке меню. Необязательные поля:

| Поле | Что значит |
|---|---|
| `languages` | Для каких определённых языков открывается автоматически. `"*"` — запасной, `[]` — только вручную |
| `suffix` | Дописывается к запросу *до* URL-кодирования — удобно для поисковиков и запросов к ИИ |
| `external` | `true` — открывать в браузере по умолчанию, а не во встроенном окне (для сайтов, где нужен ваш вход) |

**Ваши записи сохраняются при любых действиях** — смена родного языка, отметка нового исходного языка:
ничто из этого не трогает то, что вы добавили.

Есть две оси, определяющие, что откроется:

- **Искать перевод на** — один язык, куда попадают определения. Строка меню → *Искать перевод на*.
- **Также искать** — какие иностранные языки вам встречаются. Строка меню → *Также искать*, отмечайте сколько нужно.

Корейский идёт в двуязычный словарь Naver, каждый другой отмеченный язык получает запись Glosbe
(`glosbe.com/<откуда>/<куда>/<слово>`), а там есть практически любая пара. Выделили итальянское слово —
открылся итальянский словарь, корейское — Naver. Переключать вручную не нужно.

**Любая ваша запись, заявившая язык, заменяет сгенерированную по умолчанию.**

### Словарная программа вместо сайта

Если у вас установлена словарная программа, поиск может открывать её, а не веб-страницу. Строка меню →
**Локальные словари** перечисляет те, что действительно установлены на вашем Mac; неустановленные не показываются.

Работает это потому, что такие программы регистрируют собственную URL-схему, а всё помеченное `external`
передаётся системе, а не грузится во встроенном окне:

```jsonc
{ "id": "local-eudic", "name": "Eudic", "languages": ["en"],
  "url": "eudic://dict/{q}", "external": true }
```

Отмеченная программа добавляется **только для ручного выбора** — словарные приложения обычно знают много
языков, и решать, за какой отвечает эта, вам. Пропишите ей `languages`, и она заберёт этот язык себе.

Файл настроек: `~/Library/Application Support/com.quickdict.app/config.json`

Как добавить язык в пресеты и как устроен исходный код — см. [README на английском](README.md).
