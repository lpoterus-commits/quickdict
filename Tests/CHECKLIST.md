# 朗读功能验收清单

**为什么有这份东西**：朗读这一块的毛病总是「修好一处、漏掉另一处」——
共同点是**没人把整个面按顺序过一遍**，只盯着刚改的那一处。

用法：改动朗读相关的任何东西之后，从头到尾走一遍。
带 `[自动]` 的由测试覆盖，跑脚本即可；带 `[手动]` 的必须真的点。

`✅` = 真有测例盯着（**并且反向验证过：把代码改坏它会红**）。
`⬜` = 还没写，别当成验过了。

    ./Tests/run.sh              # 全仓库，含本清单里的 [自动] 项
    ./Tests/speech/run.sh       # 朗读专项

> **3.3 起本清单瘦了一大圈。** 原来的一到四章（引擎切换 / 音色 / 语气 / 自制音色）
> 和第六章（合成过程页）都是围绕 Python 边车写的；边车整体移到了 Ausculta，
> 那些条目跟着一起走了。这里只剩「按一下把选中的文字读出来」这条路上的东西。
>
> **语音页也没了**（2026-08-25 第二轮）：它那四件事——直接合成、引擎状态、音色、
> 朗读历史——前三件随边车走了，第四件的重播和导出全靠神经引擎返回的音频，
> 系统嗓音不产生可保存的音频，两个按钮都是死的。整页删掉，朗读回到纯快捷键动作。

## 一、朗读本身

| # | 检查项 | 方式 |
|---|---|---|
| 1.1 | 清洗 / 分节 / 判语种 —— 固化的用例 | [自动] ✅ |
| 1.2 | 混排文本按文字系统切开，一句都不丢 | [自动] ✅ |
| 1.3 | **一节一段，不按句切**（系统合成器是流式的，切开只会留下生硬的接缝） | [自动] ✅ |
| 1.4 | 节尾停一拍 | [自动] ⬜ 还没写 |
| 1.5 | 停止后队列真的空掉，不会自己接着往下读 | [自动] ✅ |
| 1.6 | **停止 + 立刻重读**不会互相误伤 | [自动] ✅ |
| 1.7 | 纯符号文本不产生朗读，也不崩 | [自动] ✅ |
| 1.8 | 读不读数字的开关（`speechSkipsNumbers`）真的生效 | [自动] ✅ |
| 1.9 | 快捷键取词朗读 | [手动] |
| 1.10 | ⌘ 加减速立刻生效（变速不变调） | [手动] |
| 1.11 | 没有可读内容时给提示，不是默默无声 | [手动] |

拆掉边车之后最容易剩下的是**半截**：源码删了但文档还写着、字符串留着没人用。

| # | 检查项 | 方式 |
|---|---|---|

| 3.4 | App bundle 里没有 `Resources/qwen-tts/` | [自动] ✅ |
| 3.5 | 启动后不再有 Python 进程被拉起来 | [手动] |
